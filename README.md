# Screeps - Dec2025

This repository contains the code for our collaborative Screeps adventure, starting in December 2025.

## Overview

We are building a Screeps AI from scratch, with a focus on a "room-first" or "colony-first" strategy. The AI for our creeps is inspired by Goal-Oriented Action Planning (GOAP), which allows for flexible and intelligent decision-making.

## Current Status

We have established a basic, self-sustaining colony that can:
*   Scan rooms for energy sources.
*   Spawn harvester creeps.
*   Harvest energy and deliver it to the spawn.

The creep logic is managed by a preliminary GOAP system.
